# Listening grammar — what to recognise in spoken Cebuano

This is a recognition sheet, not a production course. Aim: when you hear a sentence, know (a) which word is the verb and whether it is past or future, (b) who is doing what, (c) what mood the particles add.

## 1. Sounds

- Five pure vowels **a e i o u**, as in Spanish or Finnish. *o/u* and *e/i* swap freely in speech: *babaye ~ babayi*, *tulo ~ tulu*, *dili ~ dile*. Don't let that throw you.
- **ng** is one sound (as in *sing*), also at the start of a word: *nga*, *ngano*. *mga* is said **manga**.
- **Hyphen = glottal stop** (a tiny catch, like the break in "uh-oh"): *bag-o*, *kan-on*, *tan-aw*, *kanus-a*, *nag-adto*.
- Stress can distinguish words (*dápit* place vs *dapít* near) but you will get it from context. Ignore for now.
- Spanish and English loanwords are everywhere and are pronounced Cebuano-style: *kwarta, pamilya, trabaho, merkado, kape, selpon, syudad*.

## 2. Word order: the "predicate" comes first

The verb, adjective or noun that says *what is happening / what something is* comes first. The subject follows.

| Cebuano | Literally | English |
|---|---|---|
| **Nikaon** si Ana. | ate — Ana | Ana ate. |
| **Gwapa** si Ana. | pretty — Ana | Ana is pretty. |
| **Naa sa balay** si Ana. | is-at home — Ana | Ana is at home. |
| **Lami** ang pagkaon. | delicious — the food | The food is delicious. |
| **Maestra** ang akong mama. | teacher — my mom | My mom is a teacher. |

There is no word for "is/are". *Gwapa siya* = She (is) pretty.

Informal speech also uses **X kay Y** ("as for X, Y"), especially in Cebu City: *Ako kay taga-Finland.* — Me, I'm from Finland. *Si Ana kay nagtrabaho.* — Ana is working.

## 3. Markers: who is who

| Marker | Before | Role | Example |
|---|---|---|---|
| **ang** | common noun | subject / "the" | *ang bata* — the child |
| **si** | a name | subject | *si Ana* |
| **og** (ug) | common noun | indefinite object: "a / some" | *Mopalit ko og isda.* — I'll buy (some) fish. |
| **sa** | common noun | location, direction, definite object, possession, time | *sa balay* — at home · *sa Lunes* — on Monday · *balay sa bata* — the child's house |
| **ni** | a name | possession / agent | *balay ni Ana* — Ana's house · *gikaon ni Ana* — eaten by Ana |
| **kang** | a name | to / for a person | *para kang Ana* — for Ana |
| **mga** | any noun | plural | *mga bata* — children |

Possession, three ways you will hear: *akong balay* / *balay nako* / *ang balay nako* — all "my house". *Balay ni Ana* — Ana's house. *Balay sa akong amiga* — my friend's house.

## 4. Verbs: read the prefix

Cebuano verbs don't mark tense so much as **aspect**: not-yet-happened vs already-started. For listening, the table below covers most of what you hear.

| You hear | Means | Example |
|---|---|---|
| **mo-** + root | will / going to / habitually | *Mokaon ko.* — I'll eat. |
| **mag-** + root | will (with some verbs; also "do together / for a while") | *Magkaon ta.* — Let's eat (together). |
| **ma-** + root | will (with "state" verbs: sleep, fall, get hurt…) | *Matulog na ko.* — I'm going to sleep. |
| **ni-** / **mi-** + root | did | *Nikaon ko.* — I ate. |
| **nag-** + root | is / was doing (ongoing) | *Nagkaon siya.* — He's eating. |
| **na-** + root | did / happened (state verbs) | *Natulog siya.* — He fell asleep / slept. |
| **gi-** + root | (someone) did it to *it* — the thing is the subject | *Gikaon nako ang isda.* — I ate the fish. (lit. eaten-by-me the fish) |
| root + **-on** / **-a** | will do it to *it* / do it! | *Kaonon nako.* — I'll eat it. · *Palita!* — Buy it! · *Tan-awa!* — Look at it! |
| **i-** + root | give / put / bring it | *Ihatag nako.* — Give it to me. |
| **naka-** / **maka-** / **ka-** + root | was able to / can | *Nakakaon na ko.* — I've managed to eat. · *Makakaon ka?* — Can you eat? · *Kabalo ko.* — I know (= *ka-hibalo*). |
| **pag-** + root | the act of …; "when …" | *pagkaon* — food / eating · *Pag-abot niya…* — When he arrived… |
| bare root | command / "let's" (with *ta*) | *Kaon!* — Eat! · *Kaon ta!* — Let's eat! · *Adto ta!* — Let's go! |

Practical shortcut: **mo/mag/ma = future**, **ni/mi/nag/na = past or now**, **gi = done to it**.

## 5. Not, none, there is

| Word | Use it for | Example |
|---|---|---|
| **dili** (di) | not — with future verbs, adjectives, nouns, "no" as an answer | *Dili ko moadto.* — I won't go. · *Dili lami.* — Not tasty. · *Dili!* — No! |
| **wala** (wa) | didn't — with past verbs; there is none; don't have | *Wala ko niadto.* — I didn't go. · *Wala'y tubig.* — There's no water. · *Wala ko'y kwarta.* — I have no money. · *Wala.* — None / nothing / no (to "did you…?"). |
| **naa** (aduna, duna) | there is; have | *Naa'y tawo.* — There's someone. · *Naa ko'y kwarta.* — I have money. |
| **ayaw** | don't (command) | *Ayaw og kaon!* — Don't eat! · *Ayaw na.* — Never mind. |

The **'y** you hear in *naa'y, wala'y, ko'y, unsa'y* is a squeezed *ang*: *naa + ang → naa'y*. In texting it's written *naay, walay, koy, unsay*.

## 6. Particles: the mood cluster

They pile up right after the first word of the sentence, together with the short pronouns. Don't worry about the exact order; just recognise the pieces.

| Particle | Adds | Example |
|---|---|---|
| **na** | already / now | *Nikaon na ko.* — I've eaten. · *Adto na ta.* — Let's go now. |
| **pa** | still / yet / more | *Wala pa.* — Not yet. · *Gusto pa ko.* — I want more. |
| **lang** / **ra** | only / just (softens) | *Diri lang.* — Just here. · *Okay ra.* — It's fine. |
| **man** | actually / anyway; softens questions | *Unsa man na?* — What's that, then? |
| **gyud** (jud) | really / for sure | *Lami gyud.* — Really tasty. |
| **ba** | turns a statement into a yes/no question | *Nikaon na ba ka?* — Have you eaten? |
| **kaayo** | very (after the adjective) | *Kapoy kaayo.* — Very tiring / so tired. |
| **pud** / **sad** | also | *Ikaw pud.* — You too. |
| **diay** | so it turns out / oh really? | *Ikaw diay!* — Oh, it's you! |
| **kaha** | I wonder / maybe | *Asa kaha siya?* — Where could she be? |
| **unta** | hopefully / should have | *Moadto unta ko.* — I was hoping to go. |
| **daw** / **kuno** | "they say", reportedly | *Sakit daw siya.* — Apparently he's sick. |

Typical stacked examples: *Nikaon na ba ka?* · *Wala pa gyud ko nikaon.* · *Diri lang man ko.* · *Lami man gyud kaayo!*

| kini / kana / kadto | ni / na / to | this / that / that over there |

| ako / ikaw / kita | ko / ka / ta | I / you / we |

## 8. Sentence frames to recognise on autopilot

| Frame | Meaning | Example |
|---|---|---|
| Naa ko'y ___ | I have ___ | *Naa ko'y kwarta.* |

| Naa'y ___ | There is (a) ___ | *Naa'y pagkaon.* |
| Wala'y ___ | There is no ___ | *Wala'y tubig.* |
| Gusto ko og ___ | I want (some) ___ | *Gusto ko og kape.* |
| Gusto ko mo___ | I want to ___ | *Gusto ko mokaon.* |
| Mo___ ko | I will ___ | *Moadto ko.* |
| Ni___ ko | I ___ed | *Nikaon ko.* |
| Dili ko mo___ | I won't ___ | *Dili ko moadto.* |
| Wala ko ni___ | I didn't ___ | *Wala ko nikaon.* |
| ___ ta! | Let's ___! | *Kaon ta! Adto ta!* |
| Ayaw ___ | Don't ___ | *Ayaw og hilak.* |
| Asa ang ___? / Asa si ___? | Where is ___? | *Asa si Mama?* |
| Unsa'y ___? | What is ___? | *Unsa'y imong ngalan?* |
| Pila ni? / Tagpila? | How much (is this / each)? | |
| ___ kaayo | very ___ | *Init kaayo.* |
| ___ na ko | I'm ___ now / already ___ | *Gutom na ko. Kapoy na ko.* |
| Taga-___ ko | I'm from ___ | *Taga-Finland ko.* |
| ___ kay ___ | ___ because ___ | *Wala ko niadto kay kapoy ko.* |
| Kabalo ka ___? | Do you know ___? | *Kabalo ka asa si Ana?* |

# Documents on how the material is made

Each folder here takes one part of the method and says how it is done and how it is checked, for any language. What a learner reads, and what an assistant works from when helping a learner, is not here: it is in the language's own folder, such as `cebuano/`.

| Folder                       | What it is |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| [`vocabulary/`](vocabulary/) | How the core words of a language are chosen, how the list is checked, and how it is changed once texts are built on it |

What belongs to one language is in that language's own `docs/` folder; for Cebuano, [`cebuano/docs/`](../cebuano/docs/).

Older documents of the same kind stay where they were written: the method in six steps in `METHOD.md`, how one text is made in `CREATING-TEXTS.md`, and woven stories in `weaving/`.

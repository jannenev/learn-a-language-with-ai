# Weaving Cebuano: what is decided and what was tried

The stories themselves are in [`../texts-woven/`](../texts-woven/); what weaving is and how it is done in general is in the top-level [`weaving/`](../../weaving/) folder.

## What is in this folder

| File                             | What it is                                                                                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| [`WORD-ORDER.md`](WORD-ORDER.md) | The commonest English words matched to the Cebuano core words, the order in which to weave them, and the rules for choosing a story's words     |
| [`SWAPS.md`](SWAPS.md)           | For each Cebuano word woven so far: which English words it has stood for, where the English was left, and in which version of each story it came |
| [`LOG.md`](LOG.md)               | What was tried and what did not work, with the reasons, oldest first                                                                           |

## Before weaving a story

1. Read `weaving/HOW-TO-WEAVE.md` for the steps and the rules for swapping.
2. Read `WORD-ORDER.md` to choose the words for each version.
3. Look up each chosen word in `SWAPS.md`, and follow what was decided unless the new story gives a reason not to.
4. Read `LOG.md`, so as not to repeat what was dropped.

## After weaving one

- Add to `SWAPS.md` any new word, any new use of an old one, and the order the words came in for the story.
- Update the "fitted" counts in the table of `WORD-ORDER.md` with the new story's figures.
- Add to `LOG.md` whatever was tried and changed, with the reason.
- A new version stays in `../texts-woven/draft/` until the learner has read and accepted it.

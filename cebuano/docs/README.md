# Cebuano: how the material was made

The material itself, the word list, the texts, the grammar notes, is one level up, in `cebuano/`. This folder holds, by topic, how a part of it was made, what was checked and what was decided.

| Folder                       | What it is |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`vocabulary/`](vocabulary/) | How the word list (`../vocabulary.md`) was made, the check of it against ordinary Cebuano text and against spoken English, the questions for native speakers, and what is decided about a second version |

How these things are done for any language is in the top-level [`docs/`](../../docs/).

Older documents of the same kind stay where they were written: the plan in `../PLAN.md`, the dated log in `../LOG.md`, the listening side in `../audio.md`, and what was decided and tried for woven stories in `../weaving/`.
